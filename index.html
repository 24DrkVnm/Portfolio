Section 04 — Featured Project

NavEz

Team project · Android transit application

An Android app that helps users find bus routes between locations — including routes that need a bus switch. Built on OpenStreetMap data, from ideation to design to development as part of a team with no fixed roles.

  • Bus route discovery between any two points, with transfer-aware routing.
  • Bottom-sheet UI for location search and route display.
  • Geo-based alarm, weather info along the route, and crowdsourced route input.
  • Everyone did everything — ideation, design, and development.
